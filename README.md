1.- Ejecutar main_vision.py
2.- La contraseña es [Cuadrado, Circulo, Triángulo, Cuadrado] y se puede cambiar
3.- Hay modo una persona y modo dos personas (con un circulo en el lateral se cambia de modo):
    1.- Modo una persona:
      Se utilizarán las caras de la carpeta de fotos para cambiar de cara.
    2.- Modo dos personas:
      Se intercambiarán las caras entre las dos personas.
4.- Con el triángulo en el lateral se sale de la aplicación.
